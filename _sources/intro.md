```{tab-item} Things I learned
* It was necessary to use virtual environment for this assignment, because the previous Jupyter Book (JB) v1 and python v<=3.10 was required to follow the instructions, i.e. to use the 'create' and 'build' commands for JB
* Building a JB from modular markdown files is a way to create a quickly and easily updateable website
* Jupyter notebooks can be used for data science projects and then used directly in JB for external presentation
```

```{tab-item} Things I found difficult
* The syntax can change enough between versions of a package like JB that some of the syntax we learned has been superseded, but I found workarounds
* Small mistakes in Markdown syntax that are difficult to spot can prevent your file being displayed as you wish, e.g. only using single spaces when you want two spaces for a new line
* References take a bit longer to set up and get working correctly
```
